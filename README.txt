ROLETA DAS PERGUNTAS

Arquivos web recuperados diretamente do APK enviado.

TESTAR LOCALMENTE
Abra index.html no navegador. Se preferir, execute na pasta: python -m http.server 8000
Depois acesse http://localhost:8000.

PUBLICAR NA VERCEL
1. Envie index.html, app.js e vercel.json para a raiz de um repositório GitHub.
2. Na Vercel, escolha Add New > Project e importe o repositório.
3. Framework Preset: Other.
4. Build Command: vazio; Output Directory: ./ (raiz).
5. Clique em Deploy. É um site estático: não precisa de backend nem variáveis de ambiente.
